# 소방관제시스템 최종 발표자료

레퍼런스(얼굴인식 출결관리 시스템) 15장 슬라이드 스타일을 참고하여 제작한 통합 발표자료입니다.

## 구성

- `소방관제시스템_최종발표자료.pptx` — 29장 슬라이드 (아래 목차 1~4, 6~7 전체 포함, **5. 시연 동영상은 제외**)
  1. 프로젝트 개요 (프로젝트명/팀 소개, 아이디어, 유사 사이트 분석, 프로젝트 내용, 개발환경, 활용방안 및 기대효과)
  2. 프로젝트 수행 절차 및 방법 (WBS, 요구사항/기능 명세서 요약, 유스케이스, 와이어프레임, 화면별 기능 설명)
  3. 프로젝트 설계 및 구현 (서비스 구성도, 데이터 수집·활용 절차, API 명세서 요약, 주요 함수)
  4. 프로젝트 시연 (사용자 모드 / 관리자 모드 흐름)
  6. QnA
  7. 자체 평가 및 향후 개선 방향

- `명세서_Excel/` — PPTX에서 요약만 다루고 전체 원본은 Excel로 제공하는 4종 문서
  - `개발일정_WBS.xlsx`
  - `요구사항_명세서.xlsx`
  - `기능_명세서.xlsx`
  - `API_명세서.xlsx`

## 참고

- PPTX 내 표/카드에 담긴 수치(신뢰도 0.18, 디바운스 5초, 폴링 2초, 자체 평가의 "AI 모델 미탑재" 등)는 실제 코드(`app.py`, `ai/camera_manager.py`, `blueprints/*`)를 직접 확인해 검증한 내용입니다.
- `명세서_Excel`의 WBS 담당자명은 실제 팀원(노우현/박소연) 기준으로 정리했습니다.
